«Полевой атлас» — icon family "Условные знаки" (map-legend signs)

All 105 icons in this folder are ORIGINAL, custom-drawn for Pocket of Empire on a 24-unit grid
(generator: packages/client/scripts/icons-src/icons.mjs, which writes every <name>.svg here; then run
packages/client/scripts/build-icons.mjs to rebuild ../icons.generated.ts). Edit the generator, not the SVGs.
No game-icons.net (CC BY 3.0) artwork was used, traced or adapted, so no attribution line is required for them. If a later icon is adapted from game-icons.net, list it here as
  <name>.svg  <-  vendor/game-icons-zip/icons-master/<author>/<file>.svg  (CC BY 3.0, <author>)
and add "Icons: game-icons.net, CC BY 3.0" to the About screen.

Construction rules (keep when adding icons):
- viewBox 0 0 24 24, fill="currentColor", solid silhouettes ("ink stamp"), no strokes visible as outlines
- live area 2..22; cuts 1.2–1.5 units (≈1 px at 16 px); smallest solid feature 2 units
- buildings (castle, house, barracks, forge, tower, fence, mine, dismantle, age signs) stand on the shared
  ground line y 20..22, which makes the building row read as one legend
- settlements (rank tiers) stand on the same ground line and grow with the tier: хутор, деревня, город,
  крепость, столица, королевство, империя (bronze .. grandmaster); unranked is a "?" over a dashed (unsurveyed) line
- cut-outs are SVG masks per icon; Icon.tsx makes their ids unique per rendered copy
